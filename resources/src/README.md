# Фронтенд

Сайт отдаётся Laravel постранично: Blade рисует готовый HTML, а JavaScript
добавляет поведение поверх. Это не одностраничное приложение и не станет им —
страницы должны индексироваться и работать при выключенном JavaScript.

## Слои

```
src/
  app/       точка входа, общие настройки, глобальные стили
  modules/   части сайта: layout, home, course, shop, lead
  shared/    то, чем пользуются несколько модулей
```

Правило одно: **`shared` не знает про `modules`, `modules` не знают друг о друге.**
Если модулю понадобилось влезть в чужой — значит, общее нужно поднять в `shared`.
Так конструктор курсов открывает форму заявки: не через чужой DOM,
а через `shared/store/useModalStore`.

`app` знает про всех — он их и собирает.

## Устройство модуля

```
modules/shop/
  api/         адреса и их типы (endpoints.d.ts)
  components/  Vue-компоненты этого раздела
  composables/ поведение, которое подключается к готовой разметке
  services/    работа с данными, без Vue
  types/       описания сущностей
  index.ts     setupShop() — что подключить на странице
```

Не каждому модулю нужны все папки. `home` — только компоненты и типы.

## Vue-острова

Компоненты монтируются точечно: Blade ставит контейнер, а `app/config/islands.ts`
подбирает компонент по имени.

```blade
<div data-island="Reviews"
     data-props="{{ json_encode(['reviews' => $reviews], JSON_UNESCAPED_UNICODE) }}"></div>
```

Имя острова — имя файла: `modules/home/components/Reviews.vue` → `data-island="Reviews"`.
Каждый остров грузится отдельным файлом, поэтому страница без островов
не тянет ни одного лишнего килобайта.

Все острова на странице делят одну Pinia — иначе у них были бы разные
хранилища и общее состояние не работало бы.

## Типы

Файлы `types/*.d.ts` без импортов и экспортов — значит, объявленное в них
доступно везде без импорта. `IProduct`, `ICourse`, `IReview` пишутся сразу,
без `import type`. Префиксы: `I` — интерфейс, `T` — тип.

## Запросы

`shared/api` — единственный выход наружу. Токен CSRF подставляется сам.
Формы заявки намеренно остаются обычными: `method="post" action="/lead"`,
чтобы заявка уходила и без JavaScript.

## Команды

```
npm run dev          сборка на лету
npm run build        сборка для сервера (результат коммитится — на сервере нет Node)
npm run lint         ESLint с автоисправлением
npm run type-check   проверка типов
```

## Стили

`app/assets/styles/`. Глобальные подключаются в layout, остальные — постранично,
поэтому страница договора не тянет стили каталога. `mobile.css` идёт последним:
он переопределяет остальные.
